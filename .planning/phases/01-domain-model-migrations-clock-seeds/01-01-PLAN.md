<objective>
Define the canonical medical and dispatch taxonomy in `shared/taxonomy.json`, create strongly typed Python `StrEnum` classes in `backend/app/domain/enums.py`, export TypeScript type declarations in `apps/web/src/types/taxonomy.ts`, and implement automated parity tests.

Purpose: Establishes a single source of truth across Python backend logic and React frontend interfaces, preventing schema drift across clinical skills, emergency types, and responder roles.
Output: Validated `shared/taxonomy.json`, `enums.py`, `taxonomy.ts`, and passing `test_taxonomy.py`.
</objective>

ASVS L1 Threat Modeling for Plan 01-01:
- T-01-00 (Data Tampering / Schema Inconsistency): Taxonomy divergence between frontend and backend could cause invalid skill codes or unrecognized emergency types to pass validation or cause runtime crashes during triage and dispatch.
