<threat_model>
ASVS L1 Threat Modeling for Plan 01-03:
- T-01-04 (Cross-Tenant Clock Leakage): Clock offset manipulation in one demo session affecting another demo session or real emergencies. Mitigation: Clock offsets are strictly scoped to individual `demo_sessions` rows and passed explicitly via `demo_session_id`; if `demo_session_id` is None, `Clock.now()` returns real UTC time unconditionally.
- T-01-05 (Denial of Service via Heavy Password Hashing in Seed): Calculating hundreds of argon2id hashes synchronously during seed script execution could exhaust serverless resources or timeout local containers. Mitigation: Precompute a single valid argon2id hash string constant for `LifelinkDemo2026!` and use it for all seeded demo personas.
</threat_model>

         - `now(self, demo_session_id: Optional[UUID] = None, db: Optional[Session] = None) -> datetime`:
           - Returns timezone-aware UTC datetime (`datetime.now(timezone.utc)`).
           - If `demo_session_id` and `db` provided, queries `DemoSession.clock_offset_s` and adds `timedelta(seconds=offset)`.
         - `advance(self, demo_session_id: UUID, seconds: int, db: Session) -> datetime`:
           - Increments `DemoSession.clock_offset_s` by `seconds` and commits.
           - Returns new virtual time.
         - `reset(self, demo_session_id: UUID, db: Session) -> datetime`:
           - Sets `DemoSession.clock_offset_s = 0` and commits.
           - Returns reset virtual time.
       - FastAPI dependency `get_clock() -> Clock`.
  </action>
