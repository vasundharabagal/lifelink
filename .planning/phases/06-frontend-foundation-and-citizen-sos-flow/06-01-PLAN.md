<threat_model>
ASVS L1 & Frontend Threat Modeling for Plan 06-01:
- T-06-02 (Accidental SOS Trigger in Pocket / Poor Touch Ergonomics): Small touch targets cause accidental mis-clicks or delayed emergency actions. Mitigation: Enforce strict minimum 48×48px (`min-h-[48px] min-w-[48px]`) touch targets on all interactive components (Button, Call112Button).
- T-06-04 (Session Hijacking / Insecure Cookie Handling): Tokens exposed to JavaScript XSS. Mitigation: Backend uses httpOnly SameSite=Strict cookies (`ll_session`); frontend API client uses `credentials: "include"` without storing tokens in `localStorage`.
- T-06-07 (False Security Claim on Emergency Call): UI misleadingly claims 112 call was placed during demo simulation. Mitigation: UI explicitly notes that `tel:112` launches the device dialer and is hardware-dependent; never claims a call was dispatched or connected.
</threat_model>
