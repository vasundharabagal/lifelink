<threat_model>
ASVS L1 & Emergency Coordination Threat Modeling for Plan 06-02:
- T-06-01 (Rapid False-Alarm SOS Flooding): Bystanders accidentally bump SOS in pocket. Mitigation: 1.5s continuous hold threshold with progress animation + 10s auto-cancel sheet.
- T-06-03 (Location Spoofing / False Real-Location Assumption): App implies unverified demo location is real GPS. Mitigation: When GPS is denied/unavailable, UI prominently displays "Demo location used — GPS unavailable" badge and shows browser accuracy only when real satellite/cellular fix exists.
- T-06-05 (Client-Side Triage Bypass): Fast Dispatch client path tries to directly assign nearby volunteer. Mitigation: Fast Dispatch MUST issue `POST /api/v1/emergencies`, entering the backend deterministic triage rules, eligibility filtering, and scoring engines.
- T-06-06 (Form Loss on Mobile Interruption): Citizen switches to phone app or camera; intake state resets. Mitigation: `SosDraftContext` automatically writes draft state to `sessionStorage` on every input modification.
</threat_model>
