<threat_model>
ASVS L1 & Concurrency Threat Modeling for Plan 06-03:
- T-06-01 (Duplicate SOS Storm / Double-Tap Race): User taps "Send" multiple times during network latency. Mitigation: Generate a single UUIDv4 `Idempotency-Key` upon entering `/sos/review`; immediately disable button and show spinner on click; reuse identical key across network retries.
- T-06-04 (IDOR on Emergency Cancellation): Malicious user tries to cancel another user's emergency. Mitigation: API verifies caller session against `reported_by_user_id`; frontend CancelModal only targets the currently authenticated incident.
- T-06-05 (Clinical Misrepresentation / Diagnosis Claim): User mistakes automated classification for clinical diagnosis. Mitigation: ReviewCard displays prominent disclaimer: "Automated decision-support classification. Not a medical diagnosis." ProtocolViewer shows "Demo clinical guidance — unreviewed for clinical use. Call 112 for official dispatch."
- T-06-08 (Resource Exhaustion via Duplicate Dispatch): Multiple citizens report the same accident, fragmenting volunteer responders. Mitigation: 409 `POSSIBLE_DUPLICATE` dialog guides citizen to join existing incident in observer mode without double-dispatching volunteers.
</threat_model>
