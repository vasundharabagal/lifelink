<threat_model>
ASVS L1 & Algorithmic Integrity Threat Modeling for Plan 04-02:
- T-04-05 (Algorithmic Discrimination / Distance Monopoly): Closer unqualified responders crowd out qualified farther responders, or the closest volunteer is overwhelmed with dispatch spam. Mitigation: Distance alone never decides ranking; skill is weighted heavily (30) and distance is factored only through capped ETA (30) and headroom (5). Fairness (15) penalizes frequent dispatches within 24 hours.
- T-04-06 (Non-Deterministic Race / Jitter in Ranking): Equal scores result in random ordering across polls or demo runs. Mitigation: Deterministic 4-level tie-breaking: `(score_total DESC, eta_s ASC, reliability DESC, id ASC)` guarantees identical ordering on every evaluation.
- T-04-07 (ALS Resource Depletion): Critical ALS ambulances are wasted on minor P2/P3 incidents, leaving none for cardiac arrest. Mitigation: Ambulance suitability scoring gives preference to BLS (20 pts) over ALS (15 pts) for P2 and P3 incidents.
</threat_model>

  <action>
    1. Create `backend/app/orchestration/scoring.py` with community responder scoring functions:
       - `calculate_skill_score(candidate_skills: List[CandidateSkill], required_skills: List[RequiredSkill], emergency_type: EmergencyType) -> float`:
         - If no required skills: return 30.0.
         - Find best match for each required skill:
           - If candidate holds required skill with level >= req.min_level:
             - Base = 22.0.
             - Surplus = `(held_level - req.min_level) * 4.0`.
           - Else: Base = 0.0, Surplus = 0.0.
         - Secondary bonus: Count additional skills held by candidate (other than the primary matched skill) that are relevant (e.g. CPR, trauma, bleeding) = `+2.0` per skill.
         - Total skill score = `min(30.0, base + surplus + secondary_bonus)`.
       - `calculate_eta_score(eta_s: int, eta_cap_s: int = 900) -> float`:
         - Returns `30.0 * max(0.0, 1.0 - (eta_s / eta_cap_s))`.
       - `calculate_fairness_score(responses_24h: int, max_responses: float = 5.0) -> float`:
         - Returns `15.0 * max(0.0, 1.0 - (responses_24h / max_responses))`.
       - `calculate_reliability_score(acceptance_rate: float) -> float`:
         - Clamps `acceptance_rate` to `[0.0, 1.0]`.
         - Returns `10.0 * acceptance_rate`.
       - `calculate_credential_tier_score(category: ResponderCategory) -> float`:
         - Professional (`doctor`, `nurse`, `paramedic`): `10.0`
         - Certified (`emt`, `certified_first_aider`): `7.0`
         - Trained (`medical_volunteer`, `student_responder`): `4.0`
         - Other / Security: `2.0`
       - `calculate_radius_headroom_score(distance_m: float, service_radius_m: int) -> float`:
         - If `service_radius_m <= 0`: return 0.0.
         - `ratio = distance_m / service_radius_m`.
         - If `ratio <= 0.5`: return `5.0`.
         - If `ratio <= 1.0`: return `10.0 * (1.0 - ratio)`.
         - Else: return `0.0`.
       - `score_responder(candidate: CandidateProfile, emergency: EmergencyContext, clock: Clock, config: Settings) -> ScoredCandidate`:
         - Computes distance using `haversine_distance_m`.
         - Computes ETA using `calculate_eta_seconds` with `config.RESPONDER_SPEED_KMH` and `config.DETOUR_FACTOR`.
         - Computes all 6 subscores.
         - Total score = sum of subscores rounded to 1 decimal place (`min(100.0, max(0.0, round(total, 1)))`).
         - Formulates initial `reasons[]` and `caveats[]`.
         - Returns `ScoredCandidate`.
  </action>
