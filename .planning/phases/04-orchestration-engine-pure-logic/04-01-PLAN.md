<threat_model>
ASVS L1 & Safety Gating Threat Modeling for Plan 04-01:
- T-04-01 (Unverified Volunteer Dispatch): An unverified, expired, or suspended responder receives incident details or coordinates. Mitigation: Hard eligibility filter strictly requires at least one credential with `status == CredentialStatus.VERIFIED` and non-expired `expires_on >= clock.now().date()`; otherwise immediately rejected with `NOT_VERIFIED`.
- T-04-02 (Scope Leakage Between Demo and Production): Real responders receive simulation alerts or demo personas receive real emergencies. Mitigation: `SCOPE_MISMATCH` filter verifies that `candidate.demo_session_id == emergency.demo_session_id`.
- T-04-03 (Ghost Location / Stale Volunteer Telemetry): A volunteer who closed their app hours ago is dispatched based on outdated coordinates. Mitigation: Locations older than 300 seconds are rejected with `LOCATION_STALE` unless explicitly marked as a pinned demo persona (`pinned_location == True`).
- T-04-04 (Self-Dispatch Conflict of Interest): The patient or emergency reporter is dispatched to their own emergency. Mitigation: `IS_PATIENT` filter explicitly compares user IDs and rejects candidates matching `patient_user_id` or `reported_by_user_id`.
</threat_model>

<task type="auto">

  <files>backend/app/orchestration/distance.py, backend/tests/test_orchestration_distance.py</files>

  <action>
    1. Create `backend/app/orchestration/distance.py`:
       - `haversine_distance_m(lat1: float, lng1: float, lat2: float, lng2: float) -> float`:
         - Uses Earth radius $R = 6,371,000.0$ meters.
         - Returns 0.0 if coordinates are identical.
       - `calculate_eta_seconds(distance_m: float, speed_kmh: float, detour_factor: float = 1.35, min_seconds: int = 30) -> int`:
         - Converts speed to m/s: `(speed_kmh * 1000.0) / 3600.0`.
         - Applies `distance_m * detour_factor`.
         - Returns `max(min_seconds, round(travel_time))`.
       - `bounding_box_delta_deg(radius_m: float, lat: float) -> Tuple[float, float]`:
         - Calculates `lat_delta = radius_m / 111320.0`.
         - Calculates `lng_delta = radius_m / (111320.0 * max(0.01, cos(radians(lat))))`.
         - Returns `(lat_delta, lng_delta)`.
    2. Create `backend/tests/test_orchestration_distance.py`:
       - Test Haversine against known distances (e.g. Pune coordinates: DEMO_CENTER to Asha 0.8km offset).
       - Test identical coordinate distance == 0.0.
       - Test ETA calculation with default speeds (25 km/h for responders, 35 km/h for ambulances) and verify min 30s clamp.
       - Test bounding box delta calculation and confirm it encloses the target radius.
  </action>

  </verify>

       - `CandidateCredential(BaseModel)`: `credential_type: str`, `status: CredentialStatus`, `expires_on: date`.
       - `CandidateProfile(BaseModel)`:
         - `user_id: uuid.UUID`, `full_name: str`, `category: ResponderCategory`, `is_active: bool`
         - `readiness: ResponderReadiness`, `service_radius_m: int`
         - `last_lat: Optional[float]`, `last_lng: Optional[float]`, `last_location_at: Optional[datetime]`, `pinned_location: bool`
         - `acceptance_rate: float`, `responses_24h: int`, `cooldown_until: Optional[datetime]`
         - `demo_session_id: Optional[uuid.UUID]`
         - `skills: List[CandidateSkill]`, `credentials: List[CandidateCredential]`
       - `AmbulanceCandidate(BaseModel)`:
         - `id: uuid.UUID`, `callsign: str`, `unit_type: AmbulanceUnitType`, `status: AmbulanceUnitStatus`
         - `lat: float`, `lng: float`, `demo_session_id: Optional[uuid.UUID]`, `runs_24h: int = 0`
       - `EmergencyContext(BaseModel)`:
         - `emergency_id: uuid.UUID`, `lat: float`, `lng: float`
         - `priority: Priority`, `emergency_type: EmergencyType`
         - `required_skills: List[RequiredSkill]`, `protocol_id: str`
         - `patient_user_id: uuid.UUID`, `reported_by_user_id: uuid.UUID`
         - `demo_session_id: Optional[uuid.UUID]`
         - `excluded_responder_ids: Set[uuid.UUID] = Field(default_factory=set)`
         - `excluded_ambulance_ids: Set[uuid.UUID] = Field(default_factory=set)`
         - `active_responder_ids: Set[uuid.UUID] = Field(default_factory=set)`
         - `active_ambulance_ids: Set[uuid.UUID] = Field(default_factory=set)`
       - `RejectionDetail(BaseModel)`:
         - `candidate_id: uuid.UUID`, `target_kind: TargetKind`, `name_or_callsign: str`
         - `reason_codes: List[EligibilityRejectionReason]`, `summary: str`, `distance_m: Optional[float] = None`
       - All models must configure `model_config = ConfigDict(extra="forbid")`.
    2. Create `backend/app/orchestration/filters.py`:
       - `evaluate_responder_eligibility(candidate: CandidateProfile, emergency: EmergencyContext, clock: Clock, max_freshness_s: int = 300) -> Optional[RejectionDetail]`:
         - Check in priority order, accumulating all applicable reason codes:
           - `SCOPE_MISMATCH`: candidate demo session != emergency demo session.
           - `IS_PATIENT`: `candidate.user_id in (emergency.patient_user_id, emergency.reported_by_user_id)`.
           - `ACCOUNT_INACTIVE`: not `candidate.is_active`.
           - `NOT_AVAILABLE`: `candidate.readiness != ResponderReadiness.AVAILABLE` or (`candidate.cooldown_until and candidate.cooldown_until > clock.now()`).
           - `ACTIVE_ASSIGNMENT`: `candidate.user_id in emergency.active_responder_ids`.
           - `ALREADY_DECLINED_OR_EXPIRED`: `candidate.user_id in emergency.excluded_responder_ids`.
           - `NOT_VERIFIED`: no credential has `status == CredentialStatus.VERIFIED` and `expires_on >= clock.now().date()`.
           - `LOCATION_UNKNOWN`: `candidate.last_lat is None` or `candidate.last_lng is None`.
           - `LOCATION_STALE`: not `candidate.pinned_location` and (`candidate.last_location_at is None` or `(clock.now() - candidate.last_location_at).total_seconds() > max_freshness_s`).
           - Calculate Haversine distance. If `dist_m > candidate.service_radius_m`: add `OUTSIDE_SERVICE_RADIUS`.
           - `SKILL_MISMATCH`: verify if candidate holds any skill satisfying `emergency.required_skills` (holds skill with `level >= req.min_level`). If not, add `SKILL_MISMATCH`.
         - If any reason codes accumulated, return `RejectionDetail` with human-readable summary. If none, return `None`.
       - `evaluate_ambulance_eligibility(unit: AmbulanceCandidate, emergency: EmergencyContext, clock: Clock) -> Optional[RejectionDetail]`:
         - Checks: `SCOPE_MISMATCH`, `UNIT_NOT_AVAILABLE`, `ACTIVE_ASSIGNMENT`, `ALREADY_DECLINED_OR_EXPIRED`.
         - Return `RejectionDetail` if rejected, else `None`.
    3. Create `backend/tests/test_orchestration_filters.py`:
       - Parameterized test verifying that each reason code properly rejects the candidate:
         - Unverified credential (pending, rejected, expired) -> `NOT_VERIFIED`
         - Offline or busy readiness -> `NOT_AVAILABLE`
         - On active assignment -> `ACTIVE_ASSIGNMENT`
         - CPR Level 1 for severe bleeding protocol -> `SKILL_MISMATCH`
         - Stale location (>300s) -> `LOCATION_STALE` (and verify `pinned_location=True` bypasses)
         - Missing coordinates -> `LOCATION_UNKNOWN`
         - Distance exceeding service radius -> `OUTSIDE_SERVICE_RADIUS`
         - Prior declined offer -> `ALREADY_DECLINED_OR_EXPIRED`
         - Responder is patient -> `IS_PATIENT`
         - Demo session mismatch -> `SCOPE_MISMATCH`
         - Busy ambulance -> `UNIT_NOT_AVAILABLE`
       - Test that a fully eligible candidate passes (returns `None`).
  </action>
  <verify>
    <command>pytest backend/tests/test_orchestration_filters.py -v</command>
  </verify>
