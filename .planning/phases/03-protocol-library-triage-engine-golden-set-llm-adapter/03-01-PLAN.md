<threat_model>
ASVS L1 & Clinical Safety Threat Modeling for Plan 03-01:
- T-03-02 (Unsafe Triage Downgrade): Ambiguous or incomplete input leads to P3 classification, delaying life-saving ambulance dispatch. Mitigation: Red flags deterministically trigger P1_CRITICAL; confidence below 0.5 or missing conditions triggers fail-safe upward escalation to P2_SERIOUS with ambulance_required = True.
- T-03-04 (PII Leakage & Malicious Text): Untrusted free-form text contains control characters, scripts, or personal data. Mitigation: Sanitizer clamps text to 500 chars, strips non-printable characters and HTML tags, normalizes whitespace, and removes phone numbers and email addresses.
- T-03-05 (Fabricated Clinical Guidance): AI or code hallucinates arbitrary first-aid advice. Mitigation: All guidance is loaded strictly from version-controlled JSON files citing IFRC/AHA guidelines with explicit contraindications (do_not) and demo_unreviewed status badges.
</threat_model>

       - Define `RED_FLAG_CONDITIONS = {ConditionCode.NOT_BREATHING, ConditionCode.UNRESPONSIVE, ConditionCode.SEVERE_BLEEDING, ConditionCode.CHOKING, ConditionCode.CHEST_PAIN}`.
       - Define `CONDITION_PRECEDENCE`:
         1. `ConditionCode.UNRESPONSIVE`, `ConditionCode.NOT_BREATHING` -> `ProtocolId.PROT_UNRESPONSIVE`
         2. `ConditionCode.CHOKING` -> `ProtocolId.PROT_CHOKING`
         3. `ConditionCode.SEVERE_BLEEDING` -> `ProtocolId.PROT_SEVERE_BLEEDING`
         4. `ConditionCode.SEIZURE` -> `ProtocolId.PROT_SEIZURE`
         5. `ConditionCode.FRACTURE_DISLOCATION` -> `ProtocolId.PROT_TRAUMA_FALL`
         6. `ConditionCode.BURNS` -> `ProtocolId.PROT_BURNS`
         7. Fallback -> `ProtocolId.PROT_GENERAL`
       - Define `KEYWORD_RULES`: Dictionary mapping regex patterns (English + common Indian English / Hinglish terms e.g. "behosh", "khoon", "saas nahi", "chhati dard") to `ConditionCode`.
       - Implement answer mapping:
         - `awake == "no"` -> `ConditionCode.UNRESPONSIVE`
         - `breathing == "no"` -> `ConditionCode.NOT_BREATHING`
         - `breathing == "abnormal"` -> `ConditionCode.NOT_BREATHING`
         - `severe_bleeding == "yes"` -> `ConditionCode.SEVERE_BLEEDING`
         - `awake == "not_sure"` or `breathing == "not_sure"` -> apply confidence penalty (-0.2).
       - Implement `evaluate_rules(input_data: TriageInput, additional_conditions: Optional[Set[ConditionCode]] = None, source: str = "rules") -> TriageResult`:
         - Extract conditions from quick_type chip, answers, keyword regex on sanitized description, and `additional_conditions`.
         - Derive `red_flags = [c for c in observed_conditions if c in RED_FLAG_CONDITIONS]`.
         - Select primary protocol based on `CONDITION_PRECEDENCE`.
         - Map required skills from `shared/taxonomy.json` `protocol_skill_requirements` for the selected protocol.
         - Determine priority & ambulance requirement:
           - If `red_flags`: `Priority.P1_CRITICAL`, `ambulance_required = True`.
           - If other conditions present: `Priority.P2_SERIOUS`, `ambulance_required = True`.
           - If confidence < 0.5 or no conditions found: Fail-safe upward to `Priority.P2_SERIOUS`, `ambulance_required = True`, `protocol_id = PROT_GENERAL`.
           - Only if user explicitly selected minor emergency AND zero conditions detected: `Priority.P3_STABLE`, `ambulance_required = False`.
         - Return fully populated and validated `TriageResult`.
    2. Create `backend/tests/test_triage_rules.py`:
       - Test protocol loading: all 7 protocols exist, have valid fields, and have citations.
       - Test answer mapping: `awake=no` yields `UNRESPONSIVE` and `P1_CRITICAL`.
       - Test red-flag priority: `breathing=no` or `severe_bleeding=yes` triggers `P1_CRITICAL` and `ambulance_required=True`.
       - Test precedence order: cardiac arrest + bleeding selects `PROT_UNRESPONSIVE`; choking + burns selects `PROT_CHOKING`; bleeding + seizure selects `PROT_SEVERE_BLEEDING`.
       - Test fail-safe up: empty description with no answers yields `P2_SERIOUS` and `PROT_GENERAL`.
       - Test skills requirement: `PROT_UNRESPONSIVE` requires `cpr_aed >= 2`; `PROT_SEVERE_BLEEDING` requires `bleeding_control >= 2`.
       - Test input sanitizer: text clamping, HTML stripping, and PII redaction.
